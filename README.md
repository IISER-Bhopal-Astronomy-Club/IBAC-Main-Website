Welcome to the official web repository for the **IISER Bhopal Astronomy Club (IBAC)** and the **IISER Bhopal Astronomy Research Group (IBARG)** at the Indian Institute of Science Education and Research Bhopal.

---

## 🌌 Project Overview

IBAC is a premier student scientific activity club operating under the **IISERB Science Council** and the **Department of Physics**. We foster amateur astronomy, astrophotography, public science outreach, and frontier astrophysical research.

## 🔭 Key Features & Highlights

- **Cosmic Events Timeline & Stargazing**: Interactive chronological timeline view with category filtering (All, Upcoming, Past) and view toggle (Timeline vs. Grid). Features the 3-part **IBAC 101 Orientation Series** (7th, 9th, and 11th September 2026), the upcoming **Autumn Night-Sky Observation Session** (Early November 2026 placeholder), and the premier annual festival **Hunting the Heavens (HTH 2027)** on 12th January 2027.
- **Astro Gallery Carousel**: High-resolution astrophotography slideshow with custom slide controls, captions, and indicator dots.
- **Full History & Lineage**: Detailed chronicle of IBAC from founder Navin Sridhar (BS-MS 2013) through seven coordinator generations.
- **Instrument Inventory**: Details on the 14" Cassegrain telescope (GEM mount in observatory dome), 6" Newtonian Dobsonian ("Dobby"), and Olympus & Nikon binoculars.
- **Event Alert Emails Integration**: Direct subscription form to receive alerts for celestial phenomena, talks, and campus stargazing camps.
- **Interactive Team Directory**: Filterable member profiles for Faculty Advisor, Coordinators, Domain Heads, Core Committee, Club Advisors, and Alumni.

## 🚀 Running Locally

To preview or run the website locally:

```bash
# Clone the repository
git clone https://github.com/Tarun-Shekhar/IBAC.git
cd IBAC

# Start a local web server (Python 3)
python -m http.server 8080
```

Open `http://localhost:8080` in your web browser.
