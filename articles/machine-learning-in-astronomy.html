Machine Learning in Astronomy

Telescopes now collect petabytes of data. Here is how computers learn to sort the sky, and where they still struggle.

NS
Niharika Shrivastava
BS-MS 2021
- min read
In this article

    Astronomy, as we know it, is the scientific study of celestial objects such as stars, planets, galaxies, and the universe as a whole. It encompasses observing, analyzing, and understanding the physical properties, movements, origins, and evolution of objects and phenomena beyond Earth's atmosphere. So why do we need a modern and sophisticated technique like machine learning in astronomy?

    Introduction

    In recent times, humans have begun sending telescopes into space to extend their horizons and learn more about the universe than observatories on Earth alone could ever show. We now have telescopes collecting data in different wavelengths of the electromagnetic spectrum.

    As a consequence, we now have petabytes of data coming from space telescopes and ground-based observatories. Dealing with astronomical data now comes under the field of ‘Big Data.’ Besides machines, what else can assist humans in data mining and drawing scientific inferences from it?

    First of all, we formally define machine learning as a field of study that gives computers the capability to learn without being explicitly programmed. It is these far-reaching implications that have made machine learning increasingly popular among astronomers. Broadly, the field is divided into three types based on the way the algorithms work:

    • Supervised learning
    • Unsupervised learning
    • Reinforcement learning

    This article covers supervised machine learning techniques, their pros and cons, and their uses in astronomy.

    At a glance: supervised learning in astronomy

    Core idea
    Learn from labelled examples, then predict for unseen data
    Task types
    Classification and regression
    Main algorithms
    SVM, random forest, neural networks
    Used for
    Transients, solar flares, exoplanets, galaxy morphology
    Reported accuracy
    About 90% on galaxy morphology (one study)

    Supervised Machine Learning

    Supervised learning algorithms use a set of examples to learn the relationship between the different attributes of a dataset and the target variable. Once established, the relationship can be used to predict the target variable from unseen data. These algorithms can describe complex, non-linear relations between attributes and target variables, making the model more efficient than traditional model-fitting techniques where the model is pre-defined.

    Astronomical datasets contain attributes such as the spectra or light curves of stars and galaxies, and our task defines the target variables. If the target variables are discrete, the algorithms come under the classification task. If they are continuous, meaning they can take any value within a given range, they come under the regression task. According to what we want to predict, we apply these methods to find the ‘least error’ value of our variable.

    Classification or regression?Asking “is this galaxy a spiral or an elliptical?” is classification, because the answer is a category. Asking “how bright will this star be?” is regression, because the answer is a number.

    Before we look at how supervised learning helps in astronomy, here are the major algorithms. All of them can be implemented in programming languages like Python or R.

    Support Vector Machine

    The Support Vector Machine (SVM) is a popular learning model used for both classification and regression. For classification problems, we separate the data points by constructing a hyperplane, which acts as a decision boundary between classes.

    In a two-dimensional space, the hyperplane is a line that divides the space into two parts, each containing one class. If the classes are not linearly separable, SVM employs a technique called the kernel trick. This involves mapping the dataset into a higher-dimensional feature space where linear separation might be possible. Once the decision boundary is found in this transformed space, it is back-projected to the original input space, giving a non-linear decision boundary. SVM is a versatile and robust classification method available in libraries like scikit-learn.

    Decision Trees and Random Forest

    A decision tree is a tree-like graph with consecutive nodes, each representing a condition on a feature in the dataset. The tree is constructed during the training stage, with the root node initially containing the entire training set. The final tree predicts the class of a new object by following the conditions in its nodes.

    A random forest is a collection of decision trees. Different trees are trained on randomly selected subsets of the training set, and random subsets of features are used in each tree. This reduces correlations between trees and gives better generalization to new datasets through an aggregate of the individual predictions. Random forests can handle datasets with many features and are a popular machine-learning algorithm in astronomy.

    Artificial Neural Networks

    These algorithms lie at the heart of deep learning. Their name and structure are inspired by the human brain, mimicking the way biological neurons signal to one another. They consist of node layers: an input layer, one or more hidden layers, and an output layer. Each node, or artificial neuron, connects to another and has an associated weight and threshold. If the output of a node is above the threshold, that node is activated and sends data to the next layer. Otherwise, no data is passed along.

    Neural networks rely on training data to learn and improve their accuracy over time.

    Applications

    These algorithms can analyze astronomical data in a more robust and time-efficient manner. In time-domain astronomy, where we observe how objects change on timescales from seconds to decades, both in photometric and spectroscopic datasets, we can use them to identify and classify objects and transient events.

    In solar observations, computer algorithms can be used to predict solar weather phenomena such as flares. This predictive capability is crucial for mitigating the effects of solar storms on Earth's technology and infrastructure.

    Another domain where machine learning plays a pivotal role is exoplanet hunting. By analyzing the duration and amount of light blocked by potential exoplanets, we can gather information about a planet's size and orbit. Several exoplanets have been identified using machine learning, including a few in multiple-planet systems, where the signals are too complex for a human to distinguish easily.

    J48 creates decision trees by recursively partitioning data based on attribute values. It uses information gain or gain ratio to select the best attribute for splitting. It handles categorical and numeric attributes, supports pruning to prevent overfitting, and is widely used for classification tasks because of its simplicity and effectiveness. This tree was trained with 50,000 objects from the spectroscopic sample and has a minimum number of objects per leaf equal to 50.

    A recent study indicates that machine learning algorithms such as artificial neural networks can classify the morphology of galaxies with 90% accuracy, surpassing human classifications. The study used a training sample from Galaxy Zoo, which categorized the dataset into three classes: early types, spirals, and point sources/artifacts. A subset of these objects was used to train the artificial neural network (ANN), revealing that increasing the number of input parameters improves the accuracy of the results. It therefore appears promising to use machine learning for morphological classification in the next generation of wide-field imaging surveys. The Galaxy Zoo catalog stands out as an invaluable training set for such work.

    Challenges

    Despite the ease and efficiency we get, applying supervised learning algorithms to astronomical datasets presents challenges in handling uncertainty, knowledge transfer, and ensuring model interpretability. Most existing algorithms are not tailored for astronomical datasets. They assume uniform feature quality and treat the provided labels as ground truth. Astronomical datasets, characterized by noise and gaps, often have ambiguous labels from human experts.

    Supervised learning excels with datasets that have a high signal-to-noise ratio or uniform noise, but its performance depends on noise characteristics, which hinders generalization to datasets with different noise profiles. Adapting tools and creating new algorithms becomes necessary to accommodate dataset uncertainties during model construction. Advanced algorithms should offer prediction uncertainties based on intrinsic object properties and measurement uncertainties within the dataset, addressing the intricacies of astronomical data for more robust and accurate modeling.

    Key takeaways

      What to remember

    • Space telescopes and ground-based observatories now produce petabytes of data, so astronomy has become a Big Data problem.
    • Supervised learning learns from labelled examples. Classification predicts categories and regression predicts continuous values.
    • SVMs, random forests and neural networks are used for transients, solar flares, exoplanets and galaxy morphology.
    • Astronomical data is noisy and its labels are uncertain, so new algorithms that report prediction uncertainties are needed.
